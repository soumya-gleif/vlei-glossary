[[tref: keri1, authentic-chained-data-container, Authentic Chained Data Container, ACDC]]

~ A verifiable credential format with features that include normative support for chaining, use of composable JSON Schema, multiple serialization formats, namely, JSON, CBOR, MGPK, and CESR, support for Ricardian contracts, support for chain- link confidentiality and a well-defined security model derived from KERI. vLEI are ACDCs.
